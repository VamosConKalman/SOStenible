# Frontend de la demo

Aplicación React + TypeScript + Vite.

La guía de ejecución está centralizada en [README.md](../README.md) y [docs/AGENTES_Y_DEMO.md](../docs/AGENTES_Y_DEMO.md).

Desarrollo: `npm ci` y `npm run dev`. Vite reenvía `/api` a `http://localhost:8000`; inicia primero el backend según la guía raíz.

Build: `npm ci && npm run build`.
